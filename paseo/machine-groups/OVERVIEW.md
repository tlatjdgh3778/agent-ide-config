Machine groups is a sidebar view that lists workspaces under each connected host, and lets you sort them into groups you create per host. A workspace joins a group only when you put it there; nothing is grouped by path.

Groups and assignments are stored in this plugin's host settings on the daemon it is installed on, keyed by host, so install it on one daemon. Folded headers are stored per device. Choose it under Settings, Sidebar, Sidebar view.

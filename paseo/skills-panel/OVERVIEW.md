# 스킬

오른쪽 Explorer에서 이 작업 공간의 Codex 세션이 사용할 수 있는 스킬을 확인합니다. **+ → 스킬**로 탭을 열거나 Command Center에서 **스킬 패널 열기**를 선택합니다.

세션이 여러 개면 대상 세션을 고를 수 있습니다. 목록에서 스킬 이름과 설명을 검색하거나 새로고침할 수 있습니다.

스킬은 Codex가 보고한 설치 위치별로 묶입니다. 그룹 제목을 눌러 펼치거나 접을 수 있습니다. 검색하면 모든 그룹의 일치 항목이 표시됩니다. 설치 위치를 확인하기 어려운 스킬은 **위치 미확인**에 표시됩니다.

별표를 누르면 스킬이 목록 위의 **즐겨찾기**로 이동합니다. 즐겨찾기는 같은 Paseo 호스트의 다른 작업 공간에서도 사용할 수 있습니다.

스킬 이름이나 설명을 누르면 선택한 세션의 채팅 입력창에 `/스킬명`이 들어갑니다. 입력한 내용이 있으면 명령 뒤에 이어지므로 전송 전에 확인하거나 수정할 수 있습니다.

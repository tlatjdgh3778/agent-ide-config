# 워크트리 보드

Paseo에서 프로젝트별 작업 공간과 브랜치, 에이전트 상태를 한 화면에서 확인합니다. 상단의 **전체**와 폴더별 탭으로 프로젝트를 전환합니다. 검정 픽셀 고양이가 입력 필요, 작업 중, 완료 미확인, 실패, 대기를 표시합니다. 상태 버튼과 워크트리 필터는 선택한 폴더에 적용됩니다.

카드를 선택하면 하위 에이전트 관계가 함께 보입니다. 에이전트나 작업 공간을 열어 작업을 이어갈 수 있습니다. 숫자는 현재 선택한 호스트의 Paseo 데이터에서 계산됩니다. 터미널 훅이 보고한 상태처럼 개별 에이전트에 연결되지 않은 신호는 작업 공간 상태로 표시합니다.

보드가 열려 있는 동안 Codex 터미널의 질문창도 확인합니다. 응답을 기다리는 질문은 **입력 필요**에 나타나고, 질문창이 닫히면 표시가 사라집니다.

Paseo 0.17.4 이상이 필요합니다.

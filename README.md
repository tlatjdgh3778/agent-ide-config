# Agent IDE Config

에이전트 IDE별 레이아웃·플러그인 구성을 모아 둔 저장소입니다. 여러 PC에 같은 구성을 맞출 때는 같은 Git 커밋을 사용합니다.

```sh
git clone https://github.com/tlatjdgh3778/agent-ide-config.git
```

| 폴더 | 대상 | 내용 |
|---|---|---|
| [`herdr/`](herdr/README.md) | Herdr App | 레이아웃, Mod, 단축키 (`macos/`, `windows/`) |
| [`paseo/`](paseo/README.md) | Paseo | 데몬 설정과 플러그인 |

각 앱의 개별 설정, 세션 기록, 인증 정보는 각 PC에 있으며 이 저장소에는 들어 있지 않습니다.

## 라이선스

각 폴더의 안내와 `licenses/`를 참고하세요.
